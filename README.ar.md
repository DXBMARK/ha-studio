# HA Studio — ملخص بالعربية

مهارة (Skill) من **DXBMARK LLC** لتخطيط وتصميم وتوليد لوحات **Home Assistant** على مستوى تجاري: مؤشرات KPI، استهلاك الطاقة لكل جهاز، الكاميرات، الأجهزة الذكية، مراقبة Proxmox وDokploy والدومينات والنسخ الاحتياطي، والمساعد الصوتي.

- **الأساس:** Claude وClaude Code، مع توافق مع ChatGPT وCodex وGemini وAntigravity (خطوات التنصيب لكل منصة في [README.md](README.md)).
- **الأمان:** قراءة فقط افتراضيًا، لا تغيير في Home Assistant أو ملفاتك بدون إذن صريح، لا أسرار داخل الملفات، خصوصية الكاميرات مراعاة.
- **التصاميم:** Aurora وMidnight وFrost (زجاجية) مع فحص تباين WCAG وبدائل لإمكانية الوصول.
- **الملكية:** كامل الحقوق لـ DXBMARK LLC بترخيص Apache-2.0، مع حفظ حقوق المشاريع الأخرى في `THIRD_PARTY_NOTICES.md`.
- **ملاحظة:** ما لم يُختبر على نسخة Home Assistant حقيقية مذكور في `references/verification-checklist.md`.
