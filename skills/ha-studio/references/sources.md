# Sources behind the patterns

Every pattern below was checked against primary documentation or source code on **2026-10-03**. Entity ids are generated by
each integration and can differ by version and device name — always take them from your own inventory.

## Design
WCAG 2.2 contrast (1.4.3 text 4.5:1, 1.4.11 non-text 3:1) — https://www.w3.org/WAI/WCAG22/Understanding/ ; ratios in this repo are computed
by `scripts/contrast_check.py` with the WCAG relative-luminance formula.

## What is DXBMARK's own
KPI catalogue per business type, warning/critical thresholds, the three glass variants, profiles and generator logic are original DXBMARK
design decisions, not external standards. Regulated limits (for example medical-fridge ranges) must come from the client's regulator.
